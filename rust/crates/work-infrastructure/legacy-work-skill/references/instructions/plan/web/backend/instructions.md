# Web 後端需求規劃指令

指令分類狀態：已完成
指令邊界：本層只描述後端成果、資料與外部效果，不選擇架構、持久層、重試或驗證工具。

1. [強制] 後端 Plan 須界定業務成果、資料狀態、信任邊界、失敗結果及必要的營運可觀察性。
2. [強制] 涉及資料變更或外部操作時，須記錄原子性、可接受的部分成功或不確定結果，以及使用者可觀察的補救成果。
3. [強制] 涉及既有 API、資料或外部整合時，須記錄允許與禁止的相容性結果；具體契約與遷移方式留待 Task 確定。
4. [強制] 適用時須確認 API 或事件契約、資料責任、交易結果、migration 結果、外部整合及安全要求；只描述完成後必須成立的結果，不規劃測試、技術驗證或實作方式。
5. [強制] Backend Plan 的提問、選項、摘要與草案只能確認業務資料責任、資料生命週期、完成後狀態、一致性結果及可觀察失敗；不得提出或固定 schema、table、column、型別、長度、null、預設值、constraint、index、foreign key、sequence、migration 檔案或資料映射設計。
6. [強制] Backend Plan 討論涉及 API 或事件時，只能確認消費者、能力、輸入與輸出的業務語意、相容性及失敗結果；方法、路徑、參數名稱、傳輸 schema、錯誤碼與狀態碼由 Task 依專案證據固定。
