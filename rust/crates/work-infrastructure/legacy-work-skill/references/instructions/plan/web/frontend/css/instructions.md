# Web 前端 CSS 需求規劃指令

指令分類狀態：已完成
指令邊界：本層只確認樣式成果與限制，不預設設計內容、CSS 架構、命名法、工具或具體數值。

1. [強制] Plan 須確認適用的 viewport、縮放、文字方向、主題、互動狀態、列印及跨瀏覽器可觀察結果。
2. [強制] 可存取性成果須涵蓋鍵盤焦點、對比、文字縮放、減少動態效果及系統偏好中實際適用的項目。
3. [強制] 涉及既有樣式系統時須記錄允許的 token、佈局、selector 與視覺相容性結果，不得預設可全域覆寫或重新命名。
4. [強制] 色彩、字體、間距、斷點與內容由已確認需求或既有設計來源提供；Plan 不自行產生品牌或商業內容。
