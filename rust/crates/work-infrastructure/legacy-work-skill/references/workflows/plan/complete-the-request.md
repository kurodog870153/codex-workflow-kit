# Complete the request


1. Perform the user's Plan request under the loaded instructions.
2. Loading Plan instructions alone does not create or modify a Plan document. Create or modify artifacts only when the request and applicable authorization permit it.
3. Keep an unapproved formal Plan candidate in the conversation. When the user requests a checkpoint, return the discussion through the parent for independent progress saving; this permits unfinished discussion memory, not a partial formal Plan or its directories.
