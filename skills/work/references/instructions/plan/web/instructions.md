# Web 需求規劃指令

指令分類狀態：已完成
指令邊界：本層只補充 Web 需求的使用者可觀察結果，不規定 HTTP、框架或文件產生方式。

1. [強制] Web Plan 須界定使用者、消費者、公開邊界、主要互動及可觀察結果；路由、參數、狀態碼與實作方式留待 Task 確定。
2. [強制] 涉及既有消費者時，Plan 須記錄相容性目標與允許的遷移結果，但不得在證據不足時自行認定無影響。
3. [強制] 涉及非公開能力或敏感資料時，Plan 須記錄預期可存取者、不可存取者與失敗結果，技術控制留待 Task 確定。
4. [強制] 適用時須確認使用者可見行為、效能與可存取性成果；只記錄會影響成果的 Web 限制，不指定測試類型、測試檔案、框架、命令或實作步驟。
5. [強制] 前述邊界自 Plan 討論開始即適用；本層只確認跨前後端共通的 Web 需求結果，各端專屬需求由更接近的 Plan 層處理，技術與執行細節留待 Task 確定。
