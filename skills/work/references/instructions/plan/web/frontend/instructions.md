# Web 前端需求規劃指令

指令分類狀態：已完成
指令邊界：本層只確認瀏覽器端可觀察成果與品質邊界，不預設產品內容、頁面區塊、視覺文案、框架或實作方式。

1. [強制] Frontend Plan 須確認目標裝置、輸入方式、必要瀏覽器範圍、響應式結果、可存取性結果及可觀察的載入與互動品質。
2. [強制] 涉及既有介面時須確認允許與禁止的視覺、互動、路由及狀態相容性結果，不得在缺少證據時假設可以重做。
3. [強制] 動態資料、使用者輸入、錯誤、空白、載入及離線結果只描述必須成立的使用者可觀察行為；資料模型、元件與狀態管理留待 Task 決定。
4. [強制] 不得自行新增產品定位、受眾、內容結構、品牌語氣、行銷區塊或文字；缺少會影響成果的內容決策時須逐項確認。
5. [強制] Frontend Plan 的提問、選項、摘要與草案只能確認使用者可觀察的頁面、導覽、互動、狀態與相容性結果；不得提出或固定頁面路由、元件劃分、元件名稱、資料模型、狀態結構、前端 API client、請求或回應型別、檔案及套件結構。
