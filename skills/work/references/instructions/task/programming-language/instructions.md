# 程式語言任務規劃指令

指令邊界：本層確認影響成果的語言平台限制、語言選擇與專案證據；具體語言契約由適用子節點負責。

1. [強制] TASK 須依目標專案的實際來源、設定及工具鏈選擇適用的程式語言子路徑；不得從應用類型或框架名稱推定語言。
2. [強制] 已確認且影響成果的語言或框架限制須對應 TASK 驗收；不得將其他語言的限制套用於本工作，未確認的限制依 General 規則釐清。
