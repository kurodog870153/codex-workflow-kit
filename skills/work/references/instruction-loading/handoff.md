# Shared handoff procedure

1. A handoff is conversation data, separate from a private delegation envelope. Preserve incoming JSON unchanged and independently select the receiver's routes, TASK and Attempt/preflight context. Supply all confirmed skill roots for current-source verification.
2. Use `handoff build-task-to-execute` for a saved formal TASK and `handoff verify-task-to-execute` before relying on it. The CLI derives collection/index/item/instruction/skill identities from current sources; do not reconstruct machine fields or insert current hashes into historical claims.
3. Use `handoff build-execute-to-task` and `handoff verify-execute-to-task` with either the explicit current closed Attempt ID or preflight context. Closed returns bind exact Attempt bytes through attempt_sha256 and require matching current Task/Execution proof. Preflight must establish that the target TASK has not started. Formal specification changes continue through Revise under its own approval.
4. Unsaved Task discussion uses `handoff build-discussion`; it preserves the complete fixed planning_source as discussion input and grants no formal readiness. `handoff validate` verifies structure only and does not substitute for source verification.
5. Require source validation status valid before relying on saved formal claims. A stale source, skill, instruction, identity, affected ID or missing raw proof stops the operation. Preserve the handoff and evidence instead of editing them to pass validation.
6. Relay only successful rendered data in one conversation JSON block with its WORK-HANDOFF marker and actual requirement/artifact identities. Building, rendering or verifying does not change Source, TASK, Execution index, Attempt or lock state, approve semantic proposals or grant execution permission.
7. Execute still requires current preflight, worktree review and Attempt authorization. Same-session revisions use the coordinated artifact editor; recover only the owning transaction with its same approved candidate set, preserving all original history.
